Entry for the [One Line to Your Younger Self](https://make.fun/bounty/u-boothlord-one-line-to-your-younger-self-22e97f76) bounty on make.fun — one line in English, max 200 characters, that I would send back to my younger self if one line were all I got.

## The line

> I skipped my sister's wedding to finish a deck for a boss who forgot my name by Friday, and all I got was a $15 gift card and a layoff.

135 characters — first-person voice, one concrete regret (a missed wedding for a work deck), and the sting at the end: a gift card and a layoff. No second sentence, no explanation — the line does all the work.

## Run

```sh
python3 main.py   # writes the line to /output/entry.txt
```

`main.py` is deterministic: it always writes the same single line, and asserts it is one line of 1–200 characters.
